Override of EXT:bootstrap_package Resources/Private/Partials/Page/Navigation/Language.html (16.0.0). Upstream gates the link on {item.available}. The core menu sets available=0 for every language whose page has no `pages` translation record, regardless of the site's fallback configuration — see AbstractMenuContentObject::prepareMenuItemsForLanguageMenu(), which maps that case to ITEM_STATE USERDEF1, and LanguageMenuProcessor, which turns USERDEF1 into available=0. This site declares DE with fallbackType: fallback (config/sites/default/config.yaml), so every /de/ URL resolves and serves the English source. The demo has no page translations yet, so upstream would render a dead, greyed-out "Deutsch" on every page. Gate on {item.link} instead: the menu generates the link for unavailable items too, and an empty link still degrades to the plain span rather than to an anchor with an empty href. No namespace-carrying root element on purpose. The file uses only the built-in f: namespace, which needs no declaration, and upstream's wrapper made SonarCloud read the partial as a standalone page and report a missing doctype, lang and title (three Web:* rules, seen on PR #145).
