# Installed extensions

* [netresearch/nr-llm](nr-llm.md) - The nr-llm extension as this instance installs it: LLM foundation: providers, models, configurations, chat, embeddings.
* [netresearch/nr-ai-search](nr-ai-search.md) - The nr-ai-search extension as this instance installs it: Vector search and RAG chat over the site content.
* [netresearch/nr-vault](nr-vault.md) - The nr-vault extension as this instance installs it: Encrypted secrets that hold the LLM API keys.
* [netresearch/nr-mcp-agent](nr-mcp-agent.md) - The nr-mcp-agent extension as this instance installs it: Tool-using AI chat in the backend.
* [netresearch/t3-cowriter](t3-cowriter.md) - The t3-cowriter extension as this instance installs it: AI writing assistant in CKEditor.
* [netresearch/nr-landingpage](nr-landingpage.md) - The nr-landingpage extension as this instance installs it: AI-generated landing pages from templates.
* [netresearch/nr-repurpose](nr-repurpose.md) - The nr-repurpose extension as this instance installs it: Turns a page or PDF into a podcast, diagram and story.
* [netresearch/nr-browser-ai](nr-browser-ai.md) - The nr-browser-ai extension as this instance installs it: On-device page assistant in the browser.
* [netresearch/nr-llm-compat](nr-llm-compat.md) - The nr-llm-compat extension as this instance installs it: Routes LLM calls of third-party AI extensions through nr-llm.
